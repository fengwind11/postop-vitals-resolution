# Data access

- MIMIC-IV v3.1: https://physionet.org/content/mimiciv/3.1/ ; doi:10.13026/kpb9-mt58.
- SICdb v1.0.8: https://physionet.org/content/sicdb/1.0.8/ ; doi:10.13026/8m72-6j83.

Both resources require credentialed access and compliance with the applicable training/review and data use terms. Keep all raw records, row-level derivatives, identifiers, predictions, folds, and trained model objects outside the public repository.
